# E-Commerce Sales & Customer Analytics | Power BI

## 📌 Overview

An interactive **Power BI dashboard** built to analyze e-commerce sales, customer behavior, product performance, payment methods, and regional trends.

The project transforms transaction data into business-focused KPIs and actionable insights.

## 🛠️ Tools Used

* Microsoft Excel
* Power Query
* Power BI
* DAX

## 📈 Key KPIs

* **Total Orders:** 500
* **Total Sales:** ₹1.02M
* **Total Customers:** 220
* **Average Order Value:** ₹2.05K
* **Average Customer Rating:** 3.82

## 🔍 Key Insights

* **Beauty** was the highest-performing category with approximately **₹207.19K** in sales.
* **UPI** was the leading payment method with approximately **₹388K** in sales.
* **Maharashtra** recorded the highest sales at approximately **₹122.64K**.
* **Sports** had the highest average customer rating at **4.07**.
* The top 5 products generated approximately **₹249.87K** in sales.

## 📊 Dashboard Analysis

The dashboard provides analysis of:

* Monthly Sales & Order Trends
* Sales by Product Category
* Sales by Payment Method
* Sales by State
* Customer Ratings by Category
* New vs Returning Customers
* Top 5 Best-Selling Products
* Interactive filters for Product, Category, Payment Method, State and Date Range
